# 🧋 飲料訂購（專屬連結版）

公司、部門團購飲料。建立一個「訂購空間」就會得到專屬連結，把連結分享給同事，大家就能開團、點餐、管理菜單與名單，**不用帳號密碼**。

網站：https://evanchi1111-sys.github.io/office-drinks-lite/

- **一個空間一個連結**：每個空間有一組猜不到的隨機代號，資料完全分開，沒有連結的人看不到也改不了
- **開團**：選飲料店與參加的人，可分享 `?space=…&g=團編號` 連結
- **訂購**：選單位與姓名（會記住）、搜尋品項、規格／甜度／冰量／加料／備註、一次多杯、「常點的」一鍵再訂
- **還沒選購**：依單位列出還沒點的人
- **彙總**：杯數與金額、複製彙總（給店家）、複製明細（貼 Excel）、列印／下載 A4 分發單
- **菜單、名單**：有連結的人都能修改；可貼上 Excel 或上傳 CSV（支援 Big5）；菜單可匯出成 CSV（Excel 開啟、改完再匯入）
- **空間設定**：複製空間連結、改名、刪除整個空間（需輸入空間名稱確認）
- 多人同時使用時即時同步

> 想先看看？網址後面加上 `?demo` 就是示範模式（資料只存在這個瀏覽器分頁）。

需要管理密碼保護菜單與名單的版本，請用 [office-drinks](https://github.com/evanchi1111-sys/office-drinks)。

## 注意
- **連結就是鑰匙**：拿到連結的人都能看、也能修改該空間的資料，只分享給自己人。
- **請保存好連結**：忘記連結就進不去（這台裝置用過的空間會列在首頁）。

## 安全規則
- 資料表不開放網頁直接讀寫，所有讀寫都透過資料庫函式並出示空間代號。
- 杯價由資料庫依菜單計算（含加料）；團結束後訂單不能再新增、修改或刪除。
- 團不能刪除，只能「結束訂購」，訂單紀錄會一直保留。
- 頁面設定 `no-referrer`，空間代號不會透過連結來源外洩給其他網站。

## 設定
可與其他系統共用同一個 Supabase 專案（本系統資料表以 `ds_` 開頭）。
1. **SQL Editor** → **New query** → 貼上 [`supabase/setup.sql`](supabase/setup.sql) → **Run**。
2. [`js/config.js`](js/config.js) 填入 Project URL 與 publishable（anon）key。
3. 倉庫 **Settings** → **Pages** → Branch `main`、`/ (root)`。

## 檔案
| 檔案 | 用途 |
|---|---|
| `js/app.js` | 畫面與操作（首頁、空間） |
| `js/logic.js` | 彙總、未選購名單、常點的、分發單、菜單／名單解析 |
| `js/backend.js` | 資料存取（Supabase／示範模式） |
| `supabase/setup.sql` | 資料表、安全規則、資料庫函式 |
