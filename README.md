# 🧋🍗 飲料餐點訂購（專屬連結版）

公司、部門團購飲料與餐點（炸物、烤肉、蛋糕點心…）。建立一個「訂購空間」就會得到專屬連結，把連結分享給同事，大家就能開團、點餐、管理菜單與名單，**不用帳號密碼**。

網站：https://evanchi1111-sys.github.io/office-drinks-lite/

- **一個空間一個連結**：每個空間有一組猜不到的隨機代號，資料完全分開，沒有連結的人看不到也改不了
- **開團**：選店家（飲料店、餐點店可**複選**，同一個團就能同時點飲料和餐點）與參加的人，可分享 `?space=…&g=團編號` 連結；開團後可按「🏪 店家」增減店家（已經有人訂的店不能移除）
- **餐點**：店家分「飲料店」「餐點店」。餐點店沒有甜度冰量，改用份量（小份／大份…）、加購（加辣、加蛋…）、備註；品項可分類（炸物、烤肉、蛋糕點心…），點餐時可依分類篩選。訂購頁上方的店家按鈕可切換要點哪一家
- **訂購**：選單位與姓名（會記住）、搜尋品項、規格／甜度／冰量／加料／備註、一次多杯、「常點的」一鍵再訂；菜單上沒有的品項（季節限定等）可自己輸入品名與價格，會標示「自填」
- **還沒選購**：依單位列出還沒點的人
- **彙總**：品項數量與金額（多家店時每家一段，飲料算杯、餐點算份）、複製彙總（給店家，每家店一段）、複製明細（貼 Excel）、列印／下載 A4 分發單
- **菜單、名單**：有連結的人都能修改（菜單可設定店家種類、品項分類、加料／加購）；可貼上 Excel 或上傳 CSV（支援 Big5，單獨一格的列例如「炸物」會當成分類標題）；菜單與名單都可匯出成 CSV（Excel 開啟、改完再匯入）
- **空間設定**：複製空間連結、改名、刪除整個空間（需輸入空間名稱確認）
- 多人同時使用時即時同步

> 想先看看？網址後面加上 `?demo` 就是示範模式（資料只存在這個瀏覽器分頁）。

需要管理密碼保護菜單與名單的版本，請用 [office-drinks](https://github.com/evanchi1111-sys/office-drinks)。

## 注意
- **連結就是鑰匙**：拿到連結的人都能看、也能修改該空間的資料，只分享給自己人。
- **請保存好連結**：忘記連結就進不去（這台裝置用過的空間會列在首頁）。

## 安全規則
- 資料表不開放網頁直接讀寫，所有讀寫都透過資料庫函式並出示空間代號。
- 單價由資料庫依菜單計算（含加料／加購），只有「自己輸入」的品項採用訂購人填的單價（1～2000 元）；訂單只能點團裡有的店家；團結束後訂單不能再新增、修改或刪除。
- 只有「已結束」的團可以刪除（按兩次確認，訂單一併刪除）；訂購送出前會跳出確認視窗。
- 頁面設定 `no-referrer`，空間代號不會透過連結來源外洩給其他網站。

## 設定
可與其他系統共用同一個 Supabase 專案（本系統資料表以 `ds_` 開頭）。
1. **SQL Editor** → **New query** → 貼上 [`supabase/setup.sql`](supabase/setup.sql) → **Run**。（2026-10-15 以前建立的，另外依序執行 `supabase/upgrade-*.sql`；已經在用的，要用餐點功能請執行 `supabase/upgrade-04-meals.sql`）
2. [`js/config.js`](js/config.js) 填入 Project URL 與 publishable（anon）key。
3. 倉庫 **Settings** → **Pages** → Branch `main`、`/ (root)`。
